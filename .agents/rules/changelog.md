# Changelog

Moved to [`docs/changelog.md`](../../docs/changelog.md) — the single source.

Short version: write a player briefing, not a commit log. Only a new thing
they can do, a bug that bit them, or a change in how the table plays.
Skip chrome and polish (typewriter, icon labels, layout, header height) —
if you would not mention it after the sitting, it does not go in
`releases.json`.
